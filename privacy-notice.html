Privacy Notice

Effective October 18, 2026. Explains information handling for the Forge10 free OEE, takt, downtime and operations dashboard.

1. Information you enter

Current Forge10 functionality runs in your browser without an account or an application database. Your entries may include process names, shift details, dates, industry, product/activity names, quantities, reject counts, time estimates, demand, hourly cost assumptions, target reductions, reviewer names and saved-day histories. Terms acceptance is also retained in the browser.

2. Local storage and migration

Working data, up to 120 saved version 2 daily records and agreement preference use browser localStorage. Where compatible previous Forge10 version 1 records are found in the same browser, the updated tool may create local copies in the version 2 format without deleting the originals. Storage can be lost through browser deletion, private browsing, space limits or device changes; it is not a controlled, tamper-proof or synchronized database. Others using the same browser profile may have access to these records.

3. Information transmitted

The Forge10 calculation code performs its ordinary processing locally in the visitor's browser. It does not intentionally transmit entered production records to Lukas Rudolph or Forge10 or store them in a Forge10 application server. The site loads its static assets from the host. The owner cannot remotely view, restore or erase a visitor's locally stored daily records using this calculator.

4. Hosting provider information

The site uses GitHub Pages for static hosting. GitHub documents that it logs visitors' IP addresses for security purposes. Other technical information may be processed under GitHub's policies. See GitHub Pages documentation and GitHub's privacy statement.

5. CSV, printing and sharing

When you download a CSV or print/save a PDF report, your browser creates a local copy on your device. You are responsible for protecting exported files, deciding who receives them and complying with organizational data policies. Spreadsheet programs may process CSV fields differently; always inspect exported documents before sharing.

6. Sensitive and confidential inputs

Do not enter classified, export-controlled, highly confidential, regulated, or sensitive personal/company information. Local browser storage is not a secure vault. Check your employer's rules before placing internal process, part, financial or staffing information into an external website.

7. Control and retention

The dashboard offers controls to delete an individual saved version 2 day, delete all version 2 saved history, and reset only the working form. Original legacy version 1 records may remain in browser storage after version 2 deletion. Removing all such copies and the acceptance preference requires clearing the site's browser storage using your browser settings. Local data has no guaranteed retention period.

8. Changes and contact

If Forge10 later adds accounts, analytics, advertising, data uploads, or remote sync, the notice will need to be reconsidered and updated. Privacy questions can be raised through the portfolio contact section.
