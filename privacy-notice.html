Privacy Notice

Effective date: October 16, 2026. This notice explains how information is handled when you use the Forge10 OEE Tracker on Lukas Rudolph's website.

1. Information entered into the tracker

The current tracker runs in your web browser without a user account or an application database. Component names, cycle times, production quantities, reject counts, shift details, saved daily history, and the Terms of Use acceptance record are stored in that browser's local storage. The tracker does not send those entries to Lukas Rudolph or Forge10 through an application server.

2. Browser storage and control

Your browser stores the current working form and up to 120 saved production-day records. You can edit or replace your form, export history as CSV, and clear your browser's site data to remove local records and acceptance preferences. Local storage may be accessible to anyone with access to the same browser profile or device. Private/incognito sessions, privacy settings, and clearing site data may remove information without warning.

The current tracker uses browser localStorage for functional data storage and does not set its own tracking cookies. Storing acknowledgment in the browser does not create a central record of your identity or acceptance.

3. Website hosting and technical access data

This website is hosted on GitHub Pages. GitHub states that when visitors access a GitHub Pages site, their IP addresses are logged and stored for security purposes, whether or not visitors are signed in. GitHub may process other technical data under its own privacy statement. For more information, see GitHub's Pages documentation and GitHub's privacy statement.

4. Exports and external links

If you select Export History CSV, the browser creates a downloadable file on your device. You control where that file is stored and who receives it. Links to GitHub, LinkedIn, and other external sites are governed by those providers' privacy practices.

5. Sensitive business information

Do not enter classified, export-controlled, regulated personal, or highly confidential company data. Use caution with proprietary part names or production details, particularly on shared devices and when sharing CSV exports. Check applicable employer security policies before entering information.

6. Data retention and deletion

Browser-stored tracker data remains until you overwrite or delete it, clear website data, or the browser removes it. Browser retention is not guaranteed. The website owner does not receive a copy of your browser-local production records through this tool and cannot retrieve or delete those local entries remotely. GitHub's retention practices for hosting logs are controlled by GitHub.

7. Changes to this notice

If the tool's data handling changes, this notice will be updated. New features involving accounts, analytics, or server-side uploads would require a corresponding review of this notice before deployment.

8. Contact

For privacy questions, contact Lukas Rudolph using the contact information on the portfolio website.
